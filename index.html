GitHub 퍼블리싱 및 참여자 배포 센터

현재 보고 계신 플랫폼(수정사항 포함)을 단일 index.html 파일로 다운로드하여 GitHub Pages에 업로드하면 전 세계 어디서나 접속 가능한 공식 웹 링크가 생성됩니다.

1분 만에 끝내는 GitHub Pages 퍼블리싱 가이드

1

배포용 index.html 파일 다운로드

우측 상단의 [배포용 index.html 다운로드] 버튼을 눌러 현재 설정된 플랫폼 파일을 PC에 저장합니다.

2

GitHub 신규 저장소(Repository) 생성 및 파일 업로드

github.com/new에 접속하여 저장소 이름(예: busan-edu-2026)을 입력하고 Public으로 생성한 뒤, 다운로드한 index.html 파일을 업로드(Commit)합니다.

3

Settings → Pages 활성화

저장소 상단 메뉴의 [Settings] → 좌측 메뉴 [Pages]로 이동한 후, Branch를 main (또는 master)으로 선택하고 [Save]를 클릭하면 약 1분 뒤 공식 배포 URL이 발급됩니다!

터미널(Git CLI)로 바로 배포하기 
git init
git add index.html
git commit -m "Publish 2026 Busan Urban Regeneration Platform"
git branch -M main
git remote add origin https://github.com/[계정아이디]/busan-edu-2026.git
git push -u origin main
